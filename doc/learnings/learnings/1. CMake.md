

CMake is a build system generator
you describe what to build in cmakelists.txt files. cmake reads them and generates actual build files (makefiles on linux, visual studio solution in windows)

**the mental model:**

You write:         CMakeLists.txt 
CMake reads:   CMakeLists.txt
CMake writes:   Makefile (or Ninja build files) 
Make executes: Makefile → compiles your code


**Five concepts that cover 90% of CMake:**

```
1. project()       — names your project, sets version
2. add_library()   — creates a library target
3. add_executable()— creates an executable target
4. target_include_directories() — where to find headers
5. target_link_libraries()      — what to link against
```

**General rule for find_package:**

If a library is installed on your system and your code uses its headers — you need find_package. It tells CMake:

- Where the headers are (so compilation works)
- Where the library is (so linking works)

Without it the compiler can't find the headers and the linker can't find the library.

eg:

```bash
find_package(Threads  REQUIRED)
find_package(Freetype REQUIRED)
```

package in a cmake terms is two things togethor
headers - needed at compile time
library(.a or .so)  - needed at link time


**The three things find_package gives you:**

cmake

```cmake
find_package(Freetype REQUIRED)

# After this you have:
FREETYPE_FOUND         ← true/false
FREETYPE_INCLUDE_DIRS  ← path to headers
FREETYPE_LIBRARIES     ← path to library binary
```

You then use them:

cmake

```cmake
target_include_directories(my_lib PUBLIC ${FREETYPE_INCLUDE_DIRS})
target_link_libraries(my_lib PUBLIC ${FREETYPE_LIBRARIES})
```

That's the complete pattern. Headers for compilation, library for linking.

## buidling

**The two-step pattern:**

```
Step 1 — cmake -B build
         Configure — reads CMakeLists.txt, finds packages,
         generates build system. Run this when you change
         CMakeLists.txt. here build files are written in the build folder

Step 2 — cmake --build build
         Compile — actually runs the compiler on your source files.
         Run this when you change source code.
```
